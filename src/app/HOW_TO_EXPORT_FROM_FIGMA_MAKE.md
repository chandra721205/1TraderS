## 📋 **STEP-BY-STEP DOWNLOAD PROCESS**

### **Step 1: Locate Export Button**
- Look in top right corner
- Or check three-dot menu (⋮)
- Or try File → Export
- Or try keyboard shortcut (Ctrl+E / Cmd+E)

### **Step 2: Click Export**
- Export dialog opens
- Shows project details

### **Step 3: Configure Export**
- Select: ZIP Archive
- Uncheck: node_modules (if present)
- Check: Include all other files
- File name: tradie_code.zip

### **Step 4: Click Download**
- Browser download starts
- File saves to Downloads folder
- Size: ~2 MB
- Time: Few seconds

### **Step 5: Verify Download**
- Check Downloads folder
- File: tradie_code.zip
- Size: ~2 MB
- Ready to extract!

## 🆘 **TROUBLESHOOTING**

### **Problem: I don't see an Export button**

**Possible reasons:**
1. **Using preview mode** - Switch to code/edit mode
2. **Limited permissions** - Check if you're the owner
3. **Different UI version** - Figma Make updates may change UI

**Solutions:**
1. Try all locations mentioned above
2. Press `Ctrl+E` / `Cmd+E` keyboard shortcut
3. Look for "..." or "⋮" menu
4. Check File menu
5. Try right-clicking on project name

---

### **Problem: Export is grayed out**

**Possible reasons:**
- Project not saved
- Changes pending
- Limited permissions

**Solutions:**
1. Save your work first (Ctrl+S / Cmd+S)
2. Wait for auto-save to complete
3. Check you're logged in
4. Verify you own the project

---

### **Problem: Download fails or is incomplete**

**Solutions:**
1. Check internet connection
2. Try different browser
3. Clear browser cache
4. Disable browser extensions
5. Try incognito/private mode
6. Check available disk space

---

### **Problem: ZIP file won't extract**

**Solutions:**
- **Windows:** Right-click → Extract All
- **Mac:** Double-click to auto-extract
- **Linux:** `unzip tradie_code.zip`
- If corrupted, re-download

---

### **Problem: Files are in wrong location after extract**

**Solution:**
After extraction, reorganize:
```bash
cd tradie_code
mkdir src
mv App.tsx src/
mv components src/
mv contexts src/
mv styles src/
```

See DOWNLOAD_AND_SETUP_GUIDE.md for details.

## 🎯 **ALTERNATIVE: If Export is Not Available**

### **Option A: Copy Files Manually**

If Figma Make doesn't have export:

1. **Create local folder:**
```bash
mkdir tradie_code
cd tradie_code
```

2. **Copy each file:**
- Click file in Figma Make
- Select All (Ctrl+A / Cmd+A)
- Copy (Ctrl+C / Cmd+C)
- Create local file
- Paste (Ctrl+V / Cmd+V)

3. **Maintain folder structure** as shown in FILE_STRUCTURE.md

### **Option B: Use Figma Desktop App**

1. Open project in Figma desktop app
2. File → Export
3. More export options available

### **Option C: Clone from Git (if available)**

If you have Git repository:
```bash
git clone <repository-url> tradie_code
```
