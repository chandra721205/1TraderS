## ⚡ **5-Minute Setup**

### **Step 1: Extract Files**
```
Unzip tradie_code.zip to your projects folder
```

### **Step 2: Reorganize Structure**
```bash
cd tradie_code
mkdir src
mv App.tsx components contexts styles src/
```

### **Step 3: Install**
```bash
npm install
```
*Wait 2-3 minutes*

### **Step 4: Run**
```bash
npm run dev
```

### **Step 5: Open**
```
Browser opens automatically at:
http://localhost:5173
```

## 🆘 **Troubleshooting**

**Problem:** npm install fails  
**Fix:** `npm cache clean --force` then retry

**Problem:** Port 5173 in use  
**Fix:** `npx kill-port 5173` then retry

**Problem:** White screen  
**Fix:** Check that files are in `/src` folder

**Problem:** Need help  
**Fix:** Read DOWNLOAD_AND_SETUP_GUIDE.md
