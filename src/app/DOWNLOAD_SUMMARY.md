### **Issue: Download is slow**

**Solution:**
- 2 MB file should download quickly
- If slow, check your internet connection
- Try different browser
- Try different network

---

### **Issue: ZIP won't extract**

**Solution:**
- **Windows:** Right-click → Extract All
- **Mac:** Double-click to extract
- **Linux:** `unzip tradie_code.zip`
- If corrupted, re-download

---

### **Issue: npm install fails**

**Solutions:**
```bash
# Clear cache
npm cache clean --force

# Delete and retry
rm -rf node_modules package-lock.json
npm install

# Use different registry
npm install --registry=https://registry.npmjs.org/

# Check Node.js version
node --version  # Should be 18+
```

---

### **Issue: Port 5173 already in use**

**Solutions:**
```bash
# Option 1: Kill the port
npx kill-port 5173

# Option 2: Use different port
npm run dev -- --port 3000

# Option 3: Find and kill process
# Windows: netstat -ano | findstr :5173
# Mac/Linux: lsof -i :5173
```

---

### **Issue: White screen after npm run dev**

**Solutions:**
1. Check files are in `/src` folder
2. Verify `src/main.tsx` exists
3. Check browser console for errors (F12)
4. Clear browser cache (Ctrl+Shift+R)
5. Restart dev server

---

### **Issue: TypeScript errors**

**Solutions:**
- Check all files have correct imports
- Run `npm run type-check`
- Verify `tsconfig.json` exists
- Check path aliases in `vite.config.ts`
